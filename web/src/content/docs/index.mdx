import { Card, CardGrid } from '@astrojs/starlight/components';
import { COURSES } from '../../data/catalog';

export const courseCount = Object.keys(COURSES).length;
export const stageCount = Object.values(COURSES).reduce((n, c) => n + c.total, 0);
export const kubectlStages = COURSES['kubectl'].total;

## What is byok8s?

`byok8s` is a local course runner. You write one Go program and grow it across
{kubectlStages} stages until it does what `kubectl` does — find the cluster, ask the server
what it serves, resolve any resource through discovery and the RESTMapper,
print tables, select, watch, apply with server-side apply, describe, and stream
logs, exec and port-forward.

Every stage is graded against a real [kind](https://kind.sigs.k8s.io/) cluster.
Nothing inspects your source: the verdict is your program's exit code and
stdout, so any correct implementation passes.

## Start in four commands

```sh
git clone https://github.com/madhank93/byo-k8s-x && cd byo-k8s-x
mise install              # go, kind, kubectl
byok8s up                 # create the local kind cluster
byok8s run 1              # verify stage 1
```

See [Getting started](/getting-started/) for the full setup.
